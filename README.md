# دستیار هوشمند (نسخهٔ اندروید بومی)

دستیار شخصی برنامه‌ریزی روزانه — بومی Kotlin برای اندروید.

## قابلیت‌های نسخهٔ ۱

- 🧠 **پروفایل و یادآوری‌ها**: ساعت بیداری/خواب، وعده‌ها، باشگاه، عادت‌ها
- 📅 **برنامه‌سازی خودکار**: هر شب (مثلاً ۲۲:۰۰) برنامهٔ فردا ساخته می‌شود
- 🔄 **اصلاح خودکار**: بعد از ثبت «بیدار شدم»، برنامهٔ امروز دوباره چیده می‌شود و کارهای کم‌اهمیت کنار می‌روند
- 🔔 **آلارم و یادآوری**: بیداری با `setAlarmClock`، بقیه با `AlarmManager` دقیق (در صورت دسترسی) یا تقریبی
- 💬 **چت با Gemini**: هوش مصنوعی می‌تواند کار اضافه/حذف کند، عادت و یادداشت بسازد و برنامه را بازسازی کند
- 🛌 **اعلان پیش‌دستانهٔ خواب**: هنگام ساخت برنامهٔ فردا، یادآوری «بهتره زود بخوابی» نمایش داده می‌شود
- 📊 **گزارش ۷ روزه**: درصد انجام، روزهای ورزش، میانگین خواب، کارهای عقب‌افتاده
- 📝 **حافظه**: هر چیزی که می‌خواهی یادش بماند
- اجرای شبانه با **WorkManager** و بازیابی آلارم‌ها بعد از ریست‌شدن گوشی

## ساخت APK

روی این سیستم JDK/Android SDK نصب نیست؛ بنابراین APK از طریق **GitHub Actions** ساخته می‌شود:

1. پروژه را به ریپازیتوری GitHub بفرست (مثلاً `dastiyar-android`):
   ```bash
   git init
   git add .
   git commit -m "نسخه اول دستیار اندرویدی"
   git remote add origin https://github.com/<username>/dastiyar-android.git
   git push -u origin main
   ```
2. در تب **Actions**، workflow «ساخت APK اندروید (بومی)» اجرا می‌شود.
3. از صفحهٔ آخرین اجرا، artifact به نام `dastiyar-apk` را دانلود کن و روی گوشی نصب کن.

## راه‌اندازی روی گوشی

1. کلید API جمینی را از https://aistudio.google.com بگیر.
2. در برنامه: تنظیمات ← هوش مصنوعی ← کلید را وارد کن (روی خود گوشی ذخیره می‌شود).
3. تنظیمات ← پروفایل: بیداری، خواب، وعده‌ها، باشگاه و روزهای ورزش را تنظیم کن و ذخیره کن.
4. اجازهٔ اعلان و آلارم دقیق را بده.

## معماری

```
com.dastiyar.app
├─ data/        Room (Task, Habit, Slot, DayLog, ChatMsg, Memory) + DataStore (Profile, Settings) + Repository
├─ planner/     موتور برنامه‌سازی روزانه و بازچینی بعد از بیداری دیر
├─ ai/          کلاینت Gemini (REST) + پارس اکشن‌های چت
├─ notify/      کانال‌های اعلان، زمان‌بندی آلارم، AlarmReceiver، BootReceiver
├─ work/        NightlyPlanWorker (ساخت برنامهٔ فردا ساعت ۲۲)
├─ ui/          Compose — امروز، کارها، عادت‌ها، چت، گزارش، حافظه، تنظیمات
└─ util/        تاریخ شمسی، اعداد فارسی، ابزار زمان
```

## یادداشت‌ها

- تمام داده‌ها فقط روی گوشی است (Room + DataStore). هیچ سروری نداریم.
- فصل صوتی در نسخهٔ بعدی اضافه می‌شود.
- روی اندروید ۱۲+ اگر «آلارم دقیق» دسترسی نداشته باشد، برنامه به زمان‌بندی تقریبی برمی‌گردد.
- برای نسخهٔ نهایی (بازار) باید بیلد release با امضا و تنظیمات فروشگاهی اضافه شود.
